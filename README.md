# Web Cheat Sheet

Este repositório contém um documento de referência rápida (cheat sheet) com os principais conceitos de **HTML, CSS e JavaScript**, criado para consolidar o aprendizado e servir como consulta futura.

## 📌 Conteúdo
- Estrutura básica do HTML e tags mais usadas
- Seletores e propriedades essenciais do CSS
- Sintaxe e exemplos práticos em JavaScript
- Outros conceitos importantes (PWA, cache, internet)

## 🚀 Como usar
Abra o arquivo [`cheatsheet.md`](cheatsheet.md) para acessar o conteúdo completo.  
Use como guia rápido durante estudos ou desenvolvimento.
